# Support Chat API (Langfuse v2)

Flask support-chat service traced with the Langfuse Python SDK v2
(`langfuse.trace()` / `trace.generation()` low-level API). Written in 2024 and
untouched since.

```bash
pip install -r requirements.txt
export OPENAI_API_KEY=sk-... LANGFUSE_PUBLIC_KEY=pk-lf-... LANGFUSE_SECRET_KEY=sk-lf-...
python app.py
```
